## 🛠️ Пошаговая инструкция по запуску

1. **Исходный код OpenCV:** Вам качать оригинальный дистрибутив `opencv-3.1.0.exe` не надо — всё уже находится внутри этого репозитория. Директории `build` и `sources` уже развернуты в корневой папке `C:\Users\admin\PROGS\CV\`.

2. **Патч для IDE:** Файл **`2.rar`** содержит путь к заголовочному файлу и сам измененный файл для среды Embarcadero RAD Studio XE. Его необходимо скопировать в каталог вашей IDE с заменой устаревшего оригинала (соответственно вашим путям установки среды, предварительно сделав бэкап оригинала).

3. **Сборка:** Откройте среду и сразу загружайте общую группу проектов **`face_detector.groupproj`** (или `CV_dll.groupproj` для сборки DLL под Delphi). При запуске автоматически скомпилируются все необходимые статические либы, а также готовый исполняемый файл **`facedetect.exe`** (он ляжет в каталог `C:\Users\admin\PROGS\CV\LIBEXE\debug\`).

4. **Проверка работы (Детектор лиц):** 
   * **По фото:** Положите групповой портрет вашей любимой компании под именем **`2.jpg`** прямо в корень папки `C:\Users\admin\PROGS\CV\`. Запустите проект прямо из IDE — параметры запуска (`Parameters`) уже прописаны внутри проекта. Программа выделит все лица и глаза в аккуратные кружки.
   * **По веб-камере:** Если у вас подключена камера, просто сотрите `Parameters` в настройках проекта и запустите его — начнется захват видеопотока в реальном времени.

## 📂 Особенности реализации

* **Где искать правки:** Файл `facial_features_bcc.cpp` — это немного доработанный оригинальный пример `facial_features.cpp` (уже залит на гит). Многие места, где в исходный текст OpenCV были внесены точечные изменения (правка 1-2 знаков для совместимости с компилятором Билдера), помечены маркером `///ggg///`.
* **Бонусы:** В папке `haarcascades` находятся дополнительные каскады, которых не было в первоисточнике.
* **Важно:** При компиляции критически важны директивы в разделе *Conditional defines* настроек каждого конкретного проекта.
